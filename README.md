# MicroCred Frontend

This project is scaffolded and configured according to FE-GUIDE.md:
- Next.js 14+ (App Router, TypeScript, Tailwind CSS, shadcn/ui)
- API client in `src/lib/api.ts`
- Data models in `src/types/api.ts`
- Student & Admin flow structure in `src/features/`
- .env.local for API URL

## Development

- `npm run dev` — Start dev server
- `npm run build` — Production build
